L05. Logic Minimization

Lecture 05

5.12단 논리 단순화 복습과 예제

  • 목표: 식의 곱항 수를 최소로, 곱항 수가 같다면 리터럴 수를 최소로.
  • 불리언 큐브는 부울식을 시각적으로 나타내고 각 축이 변수 하나다. 카르노 맵은 다차원 공간을 2차원에 투영해서 인접한 minterm(maxterm)을 합쳐 최소화한다.

예 — 2비트 비교기

두 2비트 수 AB 와 CD 를 비교해 Feq(AB = CD), Flt(AB < CD), Fgt(AB > CD) 를 낸다.

Flt

Flt = A′C + A′B′D + B′CD

Feq

Feq = A′B′C′D′ + A′BC′D + AB′CD′ + ABCD

= A′C′(B′D′ + BD) + AC(B′D′ + BD) = (A′C′ + AC)(B′D′ + BD) = (A XNOR C)(B XNOR D)

K-map 으로 묶이지 않는 함수도 대수적으로 XNOR 구조를 찾으면 간단해진다.

5.2최소화 과정의 형식화

  • Implicant: on-set 의 1 하나, 또는 K-map 에서 합칠 수 있는 1들의 묶음 하나.
  • Prime implicant (PI): 다른 implicant 와 합쳐서 리터럴을 더 줄일 수 없는 implicant. 즉 최대로 줄어든(maximally reduced) implicant.
  • Essential prime implicant (EPI): on-set 의 어떤 원소를 덮는 PI 가 하나뿐이면 그 PI 가 EPI.

5.32단 논리 단순화의 자동화

  • Quine-McCluskey(Q-M) 방법: 정확한(exact) 방법. 논리 최소화에 매우 오래 걸린다.
  • Espresso: 휴리스틱 방법. 효율적이고(빠르고) 충분히 좋은 해를 주지만 최적이 아닐 수 있다.

Q-M 방법

  • minterm 식을 최소형으로 줄이는 정확한 알고리즘이며 컴퓨터로 프로그래밍할 수 있다.
  • K-map 은 시각적 패턴에 의존해서 사람에게 직관적이지만 그래서 자동화하기 어렵다. Q-M 알고리즘은 절차적이고 체계적이며 단계마다 표를 쓰므로 프로그램으로 구현하기 훨씬 효율적이다.
  • K-map 보다 많은 변수(약 21개)를 다룰 수 있다.
  • 두 단계(일반적인 논리 최소화 절차): ① uniting theorem XY + XY′ = X 를 반복해 minterm 식의 모든 PI 를 찾는다. ② prime implicant chart(PI chart)로 함수를 덮는 최소 PI 집합을 고른다 — EPI 를 찾고, 남은 minterm 을 덮는 최소 PI 집합을 찾는다.

Step 1 — 모든 PI 찾기

  • 두 곱항이 정확히 한 변수만 다르면 합친다. ABC + ABC′ = AB.
  • 컴퓨터 표현에는 위치 이진 표기인 cube notation 을 쓴다. ABC = 111, ABC′ = 110 이고 합치면 11− (− 는 줄어든 변수). 1의 개수는 3 과 2.
  • 따라서 두 곱항은 1의 개수가 정확히 1 차이날 때만 합칠 수 있다(인접한 항). 그래서 곱항을 1의 개수에 따라 그룹으로 나눈다.

F(A,B,C,D) = Σm(0,1,2,5,6,7,8,9,10,14) — 10개의 minterm

① minterm 전개를 구한다. ② 1의 개수로 그룹을 나눈다. 그룹 i 는 1이 i개인 곱항이고, 이웃한 그룹(i 와 i±1)끼리만 합칠 수 있다.

PI: B′C′, B′D′, CD′, A′C′D, A′BD, A′BC

PI 를 전부 더한 식 F = B′C′ + B′D′ + CD′ + A′C′D + A′BD + A′BC 는 최소형이 아니라 PI 의 모음일 뿐이다. 최소형은 PI chart 로 찾는다.

  • EPI 찾기: 한 PI 만 덮는 minterm 열(distinguished 1-cell)을 찾으면 그 PI 가 EPI 다. m9 는 B′C′ 만, m14 는 CD′ 만 덮는다. EPI = {B′C′, CD′}.
  • EPI 가 덮는 minterm 을 지우고 남은 minterm 을 덮는 최소 PI 를 고른다. EPI 가 덮지 못하는 것은 m5, m7 뿐이고 A′BD 가 둘을 모두 덮는다. 최소 PI 집합 = {A′BD}.
  • {B′C′, CD′, A′BD} 가 모든 minterm 을 덮는 최소 집합이다.

F = B′C′ + CD′ + A′C′D (또는 A′BD)

Q-M 은 K-map 과 기능적으로 같다

  • Step 1 에서 구한 PI 는 K-map 에서 최대 묶음을 찾은 것과 같다(B′C′, B′D′, CD′, A′C′D, A′BD, A′BC).
  • Step 2 의 EPI 는 K-map 에서 한 묶음만 덮는 1(m9, m14)로 찾는 것과 같다. 남는 m5 를 덮는 최소 PI 는 A′BD 와 같은 식으로 고른다.

Espresso

  • Espresso 는 휴리스틱 논리 최소화 알고리즘의 이름이자 소프트웨어 이름이다. 상용 CAD 도구에서 가장 많이 쓰인다.
  • EXPAND, IRREDUNDANT COVER, REDUCE 를 반복한다.
  • 예: 4 PI 로 시작한 첫 해(좋지만 최소는 아님) → REDUCE → EXPAND 로 서로 다른 4개의 PI → 새 cover 3 PI.

Espresso 가 풀 수 있는 예

최소 cover 는 PI 3개로, {AC, A′D′, C′D} 또는 {AD, A′C′, CD′} 이다. 4개의 PI 로 덮은 해도 올바르지만 최소는 아니다. Espresso 는 이 4-PI cover 에서 REDUCE 와 EXPAND 를 거쳐 3-PI cover 를 찾는다.

5.4요약

  • K-map 으로 형식화한 최소화: ① 모든 maximal 묶음(1과 X) ② 모든 EPI ③ 남은 1 을 덮는 최소 PI.
  • 자동화(교재 3.2): Q-M 방법은 정확하지만 오래 걸린다. Espresso 는 휴리스틱으로 효율적이지만 경우에 따라 최소식을 주지 못한다.
