L05. Logic Minimization

Lecture 05

5.12단 논리 단순화 복습과 예제

PI = 더 이상 확장할 수 없는 implicant. EPI = on-set minterm 하나를 덮는 PI 가 그것 하나뿐일 때의 그 PI.

  • 목표: 곱항 수 최소. 같으면 리터럴 수 최소.
  • 불리언 큐브: 부울식을 시각화, 축 하나가 변수 하나. 카르노 맵: 다차원 공간을 2차원에 투영해 인접한 minterm(maxterm)을 합침.

Flt

Flt = A′C + A′B′D + B′CD

Feq

Feq 인수분해 — 먼저 진리표의 on-set에서 SOP를 구한다.

Feq = A′B′C′D′ + A′BC′D + AB′CD′ + ABCD

A와 C의 값이 같은 항끼리 묶으면 Feq = A′C′(B′D′ + BD) + AC(B′D′ + BD)

공통 인수 (B′D′ + BD)를 추출하면 Feq = (A′C′ + AC)(B′D′ + BD)

XNOR의 정의 X XNOR Y = X′Y′ + XY를 적용하면 Feq = (A XNOR C)(B XNOR D)

이 최종식은 각 비트쌍의 일치 여부를 XNOR로 계산한 뒤 두 결과를 AND하는 구조이다. 최소 SOP 표현과 XNOR을 이용한 인수분해 표현을 구별한다.

이 비교기에서 Feq의 1들은 K-map에서 서로 인접하지 않으므로 최소 SOP는 네 개의 4리터럴 minterm으로 구성된다. 그러나 두 2비트 수가 같으려면 A=C와 B=D가 동시에 성립해야 하므로, Feq를 (A XNOR C)(B XNOR D)로 인수분해할 수 있다. 이는 XNOR 게이트를 사용할 때 간결한 표현이며, 최소 SOP와는 구별해야 한다. K-map의 1들이 묶이지 않는 모든 함수가 XNOR 곱으로 인수분해되는 것은 아니다.

Fgt

Fgt = AC′ + BC′D′ + ABD′. 특히 Fgt = Σm(4,8,9,12,13,14)이고, AB > CD라는 조건을 직접 최소화하거나 Flt의 두 비교 대상을 서로 바꾸어 동일한 결과를 얻을 수 있다.

5변수 K-map

  • 변수가 5개면 4변수 맵 두 개(A = 0, A = 1)로 그림. 두 맵의 같은 위치에 있는 셀끼리 인접하므로 묶음이 맵을 건너갈 수 있음.

예 · F(A,B,C,D,E) = Σm(2,5,7,8,10,13,15,17,19,21,23,24,29,31)

  • CE: 두 맵 모두에서 BC ∈ 01, 11 이고 DE ∈ 01, 11 인 8셀 묶음 (m5, 7, 13, 15, 21, 23, 29, 31).
  • AB′E: A = 1 맵에서 BC ∈ 00, 01 이고 DE ∈ 01, 11 (m17, 19, 21, 23).
  • A′C′DE′: A = 0 맵의 양 끝 열(BC = 00, 10)은 말려서 인접. DE = 10 (m2, 10).
  • BC′D′E′: BC = 10, DE = 00 셀을 두 맵에 걸쳐 묶음 (m8, 24).

F = CE + AB′E + A′C′DE′ + BC′D′E′

5.2최소화 과정의 형식화

Implicant
on-set 의 1 하나, 또는 K-map 에서 하나의 곱항으로 합칠 수 있는 1들의 묶음. 0 인 칸은 덮지 않음.
Prime implicant (PI)
다른 implicant 와 합쳐서 리터럴을 더 제거할 수 없는 implicant (maximally reduced).
Essential prime implicant (EPI)
on-set 원소 하나를 덮는 PI 가 단 하나뿐이면, 그 PI 가 EPI.

5.32단 논리 단순화의 자동화

Quine-McCluskey(Q-M) 방법
exact 방법. 최소화에 시간이 아주 오래 걸림.
Espresso
휴리스틱 방법. 빠르고 꽤 좋은 해를 주지만 최적이 아닐 수 있음.

Q-M 방법

  • minterm 식을 최소형으로 줄이는 정확한 알고리즘. 컴퓨터로 프로그래밍 가능.
  • K-map 은 시각적 패턴에 의존해서 사람한테는 쉽지만 자동화가 어려움. Q-M 은 절차가 정해져 있고 단계마다 표를 쓰므로 프로그램으로 구현하기 훨씬 낫다.
  • K-map 보다 많은 변수까지 처리 가능 (슬라이드: ~ 21 variables).
  • 2단계 절차. ① uniting theorem XY + XY′ = X 를 반복해서 minterm 식의 PI 를 전부 찾음. ② prime implicant chart(PI chart)로 EPI 를 찾고, 남은 minterm 을 덮는 최소 PI 집합을 고름.

Step 1: 모든 PI 찾기

  • 두 곱항이 한 변수만 다르면 합침. ABC + ABC′ = AB.
  • 컴퓨터에서는 cube notation. ABC = 111, ABC′ = 110, 합치면 11− (− 는 줄어든 변수). 1의 개수는 3 과 2.
  • 한 변수만 다른 두 곱항은 1 의 개수가 정확히 1 차이. 따라서 1 의 개수가 1 차이 나는 곱항끼리만 합칠 수 있음. 곱항을 1 의 개수별로 그룹 지음.

F(A,B,C,D) = Σm(0,1,2,5,6,7,8,9,10,14), 10개의 minterm

① minterm 전개 ② 1의 개수로 그룹 나누기. 그룹 i = 1이 i개인 곱항. 이웃한 그룹(i, i±1)끼리만 합칠 수 있음.

  • EPI 찾기: 한 PI 만 덮는 minterm 열(distinguished 1-cell)이 있으면 그 PI 가 EPI. m9 는 B′C′ 만, m14 는 CD′ 만 덮음. EPI = {B′C′, CD′}.

Step 3. EPI를 모두 선택하고 이들이 덮는 on-set minterm 열을 PI chart에서 제거한다. 남은 열이 없으면 선택을 종료한다. 남은 열이 있으면 각 minterm을 덮을 수 있는 PI들의 조합 중 모든 남은 minterm을 덮는 cover를 찾는다. 정확한 선택에는 Petrick's method 또는 가능한 PI 부분집합의 완전 탐색을 사용할 수 있다. Petrick's method에서는 PI i를 선택한다는 불리언 변수 pᵢ를 도입한다. 각 남은 minterm mⱼ에 대해 그 minterm을 덮는 PI 선택 변수들의 OR를 만들고, 이 OR들을 모두 AND한 식 P = ∏ⱼ(∑_{i: PIᵢ covers mⱼ} pᵢ)을 구성한다. 분배법칙과 흡수법칙으로 식을 정리하여 모든 minterm을 덮는 PI 조합을 구한다. 그중 선택된 PI 수가 최소인 조합을 선택하고, 동률이면 PI들의 전체 리터럴 수가 최소인 조합을 선택한다. EPI를 포함한 이 조합이 최소 SOP cover가 된다. PI를 가장 많이 덮는 순서로 탐욕적으로 고르는 방법만으로는 전역 최적성이 보장되지 않는다.

이 예제에 적용하면 EPI인 B′C′와 CD′가 덮는 열을 제거한 뒤 남는 minterm은 m5와 m7뿐이다. m5를 덮는 PI는 A′C′D와 A′BD, m7을 덮는 PI는 A′BD와 A′BC이므로 Petrick 식은 (pA′C′D + pA′BD)(pA′BD + pA′BC)가 되고, 이를 정리하면 A′BD 하나를 선택하는 조합이 최소 cover로 남는다.

  • {B′C′, CD′, A′BD} 가 minterm 을 전부 덮는 최소 집합.

Espresso

  • Espresso = 휴리스틱 논리 최소화 방법. 빠르고 충분히 좋은 해를 주지만 최적임은 보장하지 않음.

예 · Espresso의 REDUCE–EXPAND 반복

F(A,B,C,D) = Σm(0,1,2,5,6,7,8,9,10,14)를 사용한다. 초기 irredundant cover를 F = B′C′ + CD′ + A′C′D + A′BC로 선택할 수 있다. 이 cover는 네 개의 PI로 모든 on-set minterm을 덮으며, 어느 한 항을 제거해도 함수가 유지되지 않지만, 최소 cover는 아니다.

REDUCE 단계에서는 다른 항들이 이미 덮는 minterm을 고려하여 A′C′D를 m5에 해당하는 A′BC′D로, A′BC를 m7에 해당하는 A′BCD로 축소할 수 있다. m1은 B′C′가, m6은 CD′가 여전히 덮기 때문에 전체 함수는 유지된다.

다음 EXPAND 단계에서 m5와 m7을 나타내는 두 cube를 모두 PI인 A′BD로 확장할 수 있다. IRREDUNDANT COVER 단계에서 중복된 A′BD 하나를 제거하면 F = B′C′ + CD′ + A′BD라는 세 항의 cover가 얻어진다.

이 예제는 REDUCE로 기존 PI의 일부를 축소한 뒤 EXPAND에서 다른 PI를 선택하면 더 작은 cover를 얻을 수 있음을 보여준다. 다만 모든 반복이 반드시 항 수를 줄이거나 전역 최적해에 도달하는 것은 아니다.
