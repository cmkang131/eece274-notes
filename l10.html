L10. 산술 논리 (2) — 곱셈

Arithmetic Logic Design (2)

10.1array multiplier

  • n × n 곱셈의 부분곱 비트 xiyj 는 AND 게이트 하나로 만든다.
  • 부분곱을 자리에 맞춰 정렬하고, FA 의 2차원 배열로 더한다.
  • 구조가 규칙적이라 배치하기 쉽다.
  • 지연(critical path)은 배열의 행 수와 마지막 CPA 를 따라 간다. 행이 늘수록 길어진다.

10.2carry-save addition (CSA)

CSA 한 줄은 세 수 X, Y, Z 를 더해 두 수 S, C 로 만든다.

S = X ⊕ Y ⊕ Z (비트별 합)    C = MAJ(X, Y, Z) 를 왼쪽으로 한 칸 민 것

  • carry 를 옆 비트로 전파하지 않고 별도의 수 C 로 남겨 둔다. 그래서 한 줄의 지연이 FA 하나로 고정된다.
  • 수가 여러 개이면 CSA 를 차례로 쌓아 두 수로 줄이고, 마지막에 한 번만 carry 를 전파하는 가산기(CPA)로 더한다.

예 — 0001 + 0111 + 1101 + 0010

단계XYZSC (한 칸 이동)
4-bit CSA000101111101101101010
5-bit CSA01010010110001000011010100
CPA010100000011010111

첫 줄은 세 수를 더해 S = 1011, C = 0101 을 만든다. C 는 한 칸 왼쪽으로 밀어 01010 으로 쓴다. 이 줄에는 넷째 수 0010 이 아직 들어오지 않는다.

둘째 줄은 01010, 01011(= S 앞에 0), 00010(= 넷째 수) 를 더해 S = 00011, C = 01010(한 칸 밀면 010100) 을 만든다.

마지막에 010100 + 000011 = 010111 이다. 1 + 7 + 13 + 2 = 23 = 101112 와 같다.

  • array multiplier 의 CSA array 는 이 구조를 부분곱에 적용한 것이다. 맨 아래 CPA 한 줄만 carry 를 전파한다.
