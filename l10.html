L10. Arithmetic Logic Design (2)

Lecture 10

10.1ALU (교재 5.7)

ALU = 정수 이진수의 산술/논리 연산용 조합 네트워크.

ALU(arithmetic logic unit) = 정수 이진수에 대한 산술 또는 논리 연산을 구현하는 조합 네트워크. 부동소수점 수를 다루는 FPU 와 대비된다.

입출력내용
입력 워드A[N−1:0], B[N−1:0] (각 N비트)
모드 선택 M논리(logical) 대 산술(arithmetic)
연산 선택 S[L−1:0] (OpCode)어떤 연산을 할지 정한다
입력 상태보통 carry-in 하나
출력 워드F[N−1:0]
출력 상태상태 플래그(carry-out, overflow, …)

ALU bit slice

  • ALU 한 비트의 동작을 bit slice 라 한다. carry-in 을 1로 놓으면 아주 유용한 연산이 수행된다: B minus A (B 더하기 A 의 2의 보수).
MC0S0 S1기능설명
0 (logical)0 0Fi = AiAi 를 출력으로 전달
0 1Fi = NOT AiAi 의 보수
1 0Fi = Ai XOR BiXOR
1 1Fi = Ai XNOR BiXNOR
1 (arithmetic)00 0F = AA 전달
00 1F = NOT AA 의 보수
01 0F = A PLUS BA 와 B 의 합
01 1F = (NOT A) PLUS BB 와 A 의 보수의 합
10 0F = A PLUS 1A 증가(increment)
10 1F = (NOT A) PLUS 1A 의 2의 보수
11 0F = A PLUS B PLUS 1A 와 B 의 합 + 1
11 1F = B PLUS (NOT A) PLUS 1B minus A

ALU 구현

  • 1비트 slice 를 설계하고 이를 직렬로 연결(cascade)해 여러 비트 구조를 만든다. 성능을 제한하는 요인은 carry 의 전파다.
  • 1비트 slice 의 진리표(입력 M, S1, S0, Ci, Ai, Bi 과 출력 Fi, Ci+1)와 이를 구현한 회로(게이트 A1~A4, O1, X1~X3)가 있다.

10.2조합 곱셈기 (교재 5.8)

이진 곱셈

  • 이진 곱셈 = 피승수(multiplicand)를 더하거나 시프트하는 동작의 반복.

예 · 10101 × 110

피승수 10101(21), 승수 110(6).

10101
×110
00000(승수 LSB = 0)
10101(다음 비트 = 1, 한 칸 왼쪽)
10101(다음 비트 = 1, 두 칸 왼쪽)
1111110합 = 126

부분곱을 모두 더한 합은 1111110₂ = 126 = 21 × 6.

의사 코드

Product ← 0

N ← 승수의 비트 수

For i from 1 to N:

  If LSB(Multiplier) == 1: Product += Multiplicand

  Multiplicand << 1  // 한 비트 왼쪽 시프트

  Multiplier >> 1  // 한 비트 오른쪽 시프트

조합 곱셈기 (Combinational multiplier)

  • 곱셈기를 조합 논리 형태로 구현한다. 예: 4비트 × 4비트. 부분곱은 AiBj 의 AND 이다.

S7S6S5S4S3S2S1S0
  • 부분곱 16개를 만드는 AND 게이트 16개. 더하기는 가산기 12개(full adder 라면 각 6 게이트 = 72 게이트). 합계 88 게이트.
  • 다른 표현: 4 × 4 배열의 빌딩 블록. 빌딩 블록 하나는 full adder + AND 게이트다.

10.3여러 수의 덧셈과 carry save adder

  • k개의 N비트 수를 더한다고 하자. 예: 0001 + 0111 + 1101 + 0010 = 10111 (1 + 7 + 13 + 2 = 23). 단순한 방법은 N비트 가산기 k−1 개를 쓰는 것이다. 크고 느리다.

Carry save addition

full adder 하나는 입력 3개를 더해 출력 2개(sum, carry)를 낸다. carry 출력은 sum 출력의 2배 가중치다. full adder N개를 병렬로 둔 것을 carry save adder(CSA)라 한다. N개의 sum 과 N개의 carry-out 을 낸다. X + Y + Z = S + 2C.

CSA 로 0001 + 0111 + 1101 + 0010

단계입력SC (2C)
4-bit CSAX = 0001, Y = 0111, Z = 110110110101 → 01010
5-bit CSAX = 01010 (2C), Y = 01011 (S), Z = 000100001101010 → 10100
마지막 덧셈00011 + 1010010111

k − 2 단의 CSA 를 쓴다. 결과는 carry-save 형태(중복 표현)로 두고 마지막 단에서 실제 결과를 더한다. carry 전파는 마지막 단으로 미룬다. 결과 10111 = 23.

10.4CSA 를 이용한 부분곱 덧셈

  • 곱셈기의 임계 경로는 부분곱을 더하는 과정에 있다.
  • Wallace tree: column 덧셈은 느리다(한 번에 CSA 하나만 활동). 부분곱을 병렬로 더하면 CSA 를 log3/2(N/2) 레벨만 쓰면 된다. 배열 곱셈기(column addition)의 dot diagram 과 Wallace tree 곱셈기의 dot diagram 이 대비된다.

CSA 를 이용한 배열 곱셈기: 위쪽 CSA array 가 부분곱을 더하고 맨 아래 한 행의 CPA(carry propagate adder)가 마지막 carry 를 전파한다. 임계 경로(critical path)는 CSA array 를 대각선으로 지나 CPA 로 이어진다.
