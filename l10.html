10.1조합 곱셈기 (교재 5.8)

조합 곱셈기 (Combinational multiplier)

  • 곱셈기를 조합 논리로 구현. 예: 4비트 × 4비트. 부분곱은 AiBj 의 AND.

A3B0A2B0A1B0A0B0
A3B1A2B1A1B1A0B1
A3B2A2B2A1B2A0B2
A3B3A2B3A1B3A0B3
S7S6S5S4S3S2S1S0
  • 부분곱 16개 = AND 게이트 16개. 덧셈은 가산기 12개(full adder 는 각 6 게이트, 72 게이트). 합쳐서 88 게이트.
  • 다르게 그리면 4 × 4 배열의 빌딩 블록. 블록 하나 = full adder + AND 게이트.

10.2여러 수의 덧셈과 carry save adder

  • k개의 N비트 수를 더하는 경우. 예: 0001 + 0111 + 1101 + 0010 = 10111 (1 + 7 + 13 + 2 = 23). 단순하게는 N비트 가산기를 k−1 개 쓰면 되지만 크고 느림.

Carry save addition

  • full adder 하나는 입력 3개를 받아 출력 2개(sum, carry)를 냄.
  • carry 는 sum 의 2배 가중치.
  • full adder N개를 병렬로 둔 것이 carry save adder(CSA)이며 N개의 sum 과 N개의 carry-out 이 나옴.
  • X + Y + Z = S + 2C.

CSA 로 0001 + 0111 + 1101 + 0010

단계입력SC (2C)
4-bit CSAX = 0001, Y = 0111, Z = 110110110101 → 01010
5-bit CSAX = 01010 (2C), Y = 01011 (S), Z = 000100001101010 → 10100
마지막 덧셈00011 + 1010010111
  • CSA 는 k − 2 단.
  • 중간 결과를 carry-save 형태(S 와 2C 두 수)로 두고, 마지막 단에서 두 수를 더해 실제 합을 구함.
  • carry 전파는 마지막 덧셈 단계로 미룸.
  • 결과 10111 = 23.

10.3CSA 를 이용한 부분곱 덧셈

  • 곱셈기의 임계 경로는 부분곱 덧셈 쪽.
  • CSA 배열 곱셈기.
  • 위쪽 CSA array 가 부분곱을 더하고, 맨 아래 한 행의 CPA(carry propagate adder)가 마지막 carry 를 전파.
  • critical path는 CSA array 를 대각선으로 지나 CPA 로 이어짐.
