Mid. Mid Summary

Lecture summary

중간 범위 요약 슬라이드(Mid Summary) 12쪽의 구성이다. 각 단원의 핵심 항목을 슬라이드 순서대로 적고, 자세한 내용은 해당 단원 페이지에 있다.

M.1L03 Combinational Logic (1)

  • Combinational logic 정의. 부울 대수 정리(idempotent, complementary, distributive …).
  • DeMorgan 법칙: (X + Y + Z + …)′ = X′·Y′·Z′·…, (X·Y·Z·…)′ = X′ + Y′ + Z′ + …
  • Duality (부울식 변환용이 아니다): (X + Y + Z + …)D = X·Y·Z·…, (X·Y·Z·…)D = X + Y + Z + …
  • 논리 게이트.

M.2L04 Combinational Logic (2)

  • Boolean formula 구현. Two-level logic: canonical form (minterm / maxterm expansion), sum-of-product / product-of-sum.

Minterm expansion 예

F = A′B′C + A′BC + AB′C + ABC′ + ABC

F(A, B, C) = Σ m(1, 3, 5, 6, 7)

M.3L05 Combinational Logic (3)

  • Two-level logic simplification: Boolean cube 로 인접한 minterm 을 묶는다. 예: F = BCin + AB + ACin.
  • Karnaugh map: F = AC + B′C′, F = A′BD + B′D′ + C.

M.4L06 Logic Minimization

  • K-map 에서 최소식을 얻는 형식 절차: Step 1 모든 maximal 한 1 과 X 의 그룹(PI)을 찾는다. Step 2 모든 EPI 를 찾는다. Step 3 EPI 로 덮이지 않은 1 을 최소 개수의 PI 로 덮는다.
  • 자동화: Q-M method, Espresso.

M.5L07 Multilevel Logic / Time Response

  • Multilevel simplification (교재 3.3). Time response in combinational networks (교재 3.5): gate delay, hazard 와 glitch.
  • Static 1-hazard, static 0-hazard, dynamic hazard. K-map 에서 F = A′D + AC′ 는 hazard 가 있고, consensus 항을 더한 F = A′D + AC′ + C′D 는 hazard free 설계다.

M.6L08 Combinational Logic Technologies

  • 기본 논리 구성 요소: fixed gate, look-up table, template-based logic. Mux 를 이용한 CL 설계. PLA (programming 전과 후), PLA 구현.

M.7Number Systems

  • Positional number notation, number conversion. 이진 산술, 음수 표현(sign & magnitude, ones complement, twos complement), overflow 조건(마지막 두 carry, 부호 비트), overflow detection.

M.8L09 Arithmetic Logic (1)

  • 4-bit adder/subtractor. CLA (carry look-ahead addition): Carry Generate Gi = AiBi, Carry Propagate Pi = Ai ⊕ Bi, Ci+1 = Gi + CiPi. Hierarchical CLA.

M.9L10 Arithmetic Logic (2)

  • Array multiplier. Carry save addition: 0001 + 0111 + 1101 + 0010. 4-bit CSA 에서 S = 1011, C = 0101 (왼쪽으로 한 칸: 01010). 5-bit CSA 에서 S = 00011, C = 01010 (10100). 마지막 덧셈 00011 + 10100 = 10111.

M.10L11 Sequential Logic (1)

  • Sequential logic elements. Cross-coupled NOR gate 로 만든 R-S latch (Q⁺: 00 hold, 01 reset, 10 set, 11 forbidden). Edge-triggered D flip-flop.

M.11L12 Sequential Logic (2)

  • Timing methodology (setup, hold, clock skew, metastability, register).
