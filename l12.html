L12. 타이밍 방법론과 레지스터

Timing Methodologies and Registers

12.1setup, hold, propagation

  • setup time Tsu: clock edge 전에 데이터가 변하지 않고 안정돼 있어야 하는 시간.
  • hold time Th: clock edge 후에 데이터가 계속 안정돼 있어야 하는 시간.
  • propagation delay Tp: clock edge 후 출력 Q 가 새 값으로 바뀌기까지 걸리는 시간.
  • edge 전 Tsu 부터 edge 후 Th 까지는 입력이 변하면 안 된다. 어기면 flip-flop 이 값을 잘못 저장한다.

12.2두 가지 타이밍 제약

같은 clock 에 연결된 F/F 0 과 F/F 1 사이에 조합 논리 CL 이 있다고 하자. Tp 는 F/F 의 propagation delay, TCL 은 CL 의 지연이다.

SETUP 제약

Tclk ≥ Tp + TCL,max + Tsu

  • 가장 느린 경로가 다음 edge 의 setup 시한 안에 도착해야 한다.
  • 위반하면 clock 주기 Tclk 를 늘려서 해결한다.
HOLD 제약

Tp,min + TCL,min ≥ Th

  • 가장 빠른 경로의 새 값이 F/F 1 의 hold 시간이 끝나기 전에 도착하면, F/F 1 이 이전 값을 못 잡고 오염된다.
  • 위반하면 clock 주기를 늘려도 소용이 없다. 경로에 지연을 더해서 해결한다. 식에 Tclk 가 없다.
문제가 되는 경로해결
setup 위반가장 느린 경로clock 주기를 늘림
hold 위반가장 빠른 경로경로에 지연을 추가

12.3clock skew

  • 같은 clock 이라도 배선 길이 차이 때문에 F/F 마다 clock 이 도착하는 시각이 다르다. 이 차이가 clock skew 다.
  • F/F 0 의 clock 에 비해 F/F 1 의 clock 이 δ 만큼 늦게 도착한다고 하자.
skew 를 넣은 제약

setup: Tclk + δ ≥ Tp + TCL,max + Tsu

hold: Tp,min + TCL,min ≥ Th + δ

  • δ > 0 (받는 쪽 clock 이 늦음): setup 은 여유가 늘고 hold 는 더 어려워진다.
  • δ < 0 (받는 쪽 clock 이 빠름): setup 이 더 어려워지고 hold 는 여유가 늘어난다.
