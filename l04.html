L04. 조합 논리 (3) — 카르노 맵

Combinational Logic (3)

4.1인접성과 변수 소거

변수 하나만 다른 두 minterm 은 인접(adjacent)하다. 인접한 두 항을 합치면 그 변수가 사라진다. XY + XY′ = X

  • 2k개의 minterm 이 서로 인접하게 모여 있으면 합쳐서 k개 변수가 사라진다.
  • 불리언 큐브(boolean cube)에서는 변이 하나인 두 꼭짓점이 인접한 minterm 이다.

예 — 불리언 큐브에서 묶기

Cout = Σm(3, 5, 6, 7) 이면 꼭짓점 011, 101, 110, 111 을 칠한다.

111 과 인접한 세 점이 각각 011, 101, 110 이므로 다음 세 쌍으로 묶인다.

  • 011 + 111 → BC
  • 101 + 111 → AC
  • 110 + 111 → AB

Cout = AB + AC + BC

4.2카르노 맵 (Karnaugh map)

K-map = 진리표를 인접한 minterm 이 이웃 칸이 되도록 다시 배열한 표. 이웃한 칸의 1을 묶으면 곧 변수가 소거된다.

  • Gray code 순서: 행과 열의 라벨은 00, 01, 11, 10 순서로 쓴다. 이웃한 라벨이 한 비트만 다르다.
  • wrap-around: 맨 윗줄과 맨 아랫줄, 맨 왼쪽 열과 맨 오른쪽 열도 서로 인접하다.

4.3묶는 규칙

  • 1을 직사각형으로 묶는다. 크기는 반드시 2n개 (1, 2, 4, 8, …).
  • 가능한 한 크게 묶는다. 클수록 곱항에서 변수가 많이 사라진다.
  • 묶음끼리 겹쳐도 된다. 모든 1이 적어도 한 묶음에 들어가야 한다.
  • 묶음 하나는 곱항 하나다. 묶음 안에서 변하지 않는 변수만 남긴다.
  • X(don′t care)는 묶음을 키우는 데 도움이 될 때만 1로 쓰고, 도움이 안 되면 무시한다.

예 — 3변수 K-map

오른쪽 아래의 두 1: C = 1, A = 1 이고 B 는 변한다. → AC

양 끝의 두 1: C = 0, B = 0 이고 A 는 변한다. → B′C′

F = AC + B′C′

예 — 4변수 K-map

네 모서리: B = 0, D = 0. → B′D′

아래 두 행: C = 1. → C

혼자 남은 1: A′BD

F = A′BD + B′D′ + C

4.4PoS 구하기

  • 0을 묶어서 F′ 를 SoP 로 구한 다음 드모르간을 적용하면 PoS 가 된다.
