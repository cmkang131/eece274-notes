L04. Combinational Logic (3)

Lecture 04

4.12단 논리 최소화

정준형으로 쓴 뒤 인접한 항을 묶으면 더 간단한 2단 논리. SoP 는 출력 1인 minterm 을 묶어 곱항을, PoS 는 출력 0인 maxterm 을 묶어 합항을 줄임.

logic minimization: 같은 함수를 더 적은 비용(게이트 수, 실리콘 면적)으로 구현.

  • 2단 최소화 목표: ① 곱항 수 최소 ② 곱항 수가 같으면 리터럴 수 최소.
  • 대수적 변형만으로는 최소식을 찾았는지 보장할 수 없음. 변형 순서에 따라 더 간단한 식을 놓칠 수 있음(local minimum).
  • 체계적인 방법: 불리언 큐브, 카르노 맵, Quine-McCluskey 방법.

4.2불리언 큐브 (Boolean cube)

  • 부울식의 시각적 표현. 축 하나가 변수 하나. positional notation로 A′BC′ → 010. 노드 하나 = 입력 조합 하나. 각 입력 조합에는 minterm 하나, maxterm 하나씩 대응.
  • 1-cube(변수 1개) 선분, 2-cube(변수 2개) 정사각형, 3-cube(변수 3개) 정육면체.

진리표를 큐브에 옮기기

  • ON-set = 검은 노드, OFF-set = 흰 노드, DC-set(don’t care) = X 노드.

인접한 minterm 합치기

uniting theorem XY + XY′ = X 를 sub-cube으로 그림. 한 변수만 다른 인접한 ON-set minterm 을 묶으면 그 변수가 사라짐. 큰 원 하나 = 이렇게 합친 곱항 하나.

  • F = AB′ + AB = A (11, 10 에서 B 소거).
  • G = A′B′ + AB′ = B′.
  • H = AB + AB′ + A′B′ → A, B′ 두 묶음. H = A + B′.

4.3카르노 맵 (K-map)

  • K-map = 큐브처럼 진리표를 다르게 배치한 것. 인접한 칸 = 한 변수만 다른 조합. 그 칸들을 묶어 uniting theorem 적용.
  • 큐브는 3차원을 넘으면 그리기 어려움. 다차원 공간을 2차원에 투영한 게 K-map.
  • Gray code: 다음 인덱스로 갈 때 한 비트만 바뀜. 이웃한 두 칸의 거리는 1.
  • 한쪽 가장자리 칸은 반대쪽 가장자리 칸과 인접.

2변수

  • 칸 하나 = 진리표 행 하나. 칸 안의 값이 출력. 보통 1(과 0, X)만 적음.
  • 인접한 두 칸을 묶으면 값이 다른 변수가 사라짐. 한 칸은 리터럴 2개(AB′), 두 칸 묶음은 리터럴 1개(A). 확인은 AB′ + AB = A, 또는 그 변수에 0과 1이 다 들어 있는지 보면 됨.
  • 묶음 수 = 곱항 수. 묶음이 클수록 리터럴이 적음. 묶음은 1, 2, 4, 8 … 칸의 직사각형만 가능하고 겹쳐도 됨. 최소 SoP = 1인 칸을 전부 덮는 묶음 조합 중 곱항 수, 리터럴 수가 최소인 것.

3변수

  • minterm 위치와 인접한 칸 확인. 011(A′BC)의 이웃은 001(A′B′C), 010(A′BC′), 111(ABC).
  • SoP 는 출력 1인 칸(minterm)을, PoS 는 출력 0인 칸(maxterm)을 K-map 에 옮겨 묶음. 예: F(a,b,c) = m1 + m3 + m5 = M0M2M4M6M7.

Don’t care 다루기

  • don’t care minterm 은 X 로 표시. 최소 SoP 는 1을 전부 덮어야 하고, X 는 묶음이 커져 식이 간단해질 때만 1 로 사용. 도움이 안 되는 X 는 0 으로 두고 묶지 않음.
