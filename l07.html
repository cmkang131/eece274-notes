L07. 시간 응답 — 해저드

Time Response

7.1게이트 지연과 glitch

  • 실제 게이트는 입력이 바뀐 뒤 시간이 지나야 출력이 바뀐다. 이것이 gate delay 다.
  • 한 입력의 변화가 지연이 다른 두 경로로 출력에 도달하면, 출력이 순간적으로 잘못된 값을 낸다. 이것이 glitch 다.
  • 논리식으로는 항상 맞는 회로에서도 glitch 는 생긴다. 해저드(hazard)는 glitch 가 생길 수 있는 상태를 말한다.

7.2해저드의 종류

종류파형뜻
static-1 hazard1 → 0 → 11로 유지돼야 할 출력이 잠깐 0이 됨
static-0 hazard0 → 1 → 00으로 유지돼야 할 출력이 잠깐 1이 됨
dynamic hazard0 → 1 → 0 → 1 (또는 반대)값이 바뀌어야 하는데 여러 번 흔들린 뒤 바뀜
  • static-1 hazard 는 SoP 회로에서 생긴다. 입력 하나만 바뀌는데 출력이 서로 다른 두 곱항 사이를 넘어가는 경우다.
  • 단일 입력 변화만 생각하면, 2단 SoP 회로에는 static-0 hazard 와 dynamic hazard 가 없다.

7.3hazard-free 설계

K-map 에서 인접한 두 묶음이 서로 맞닿아 있으면, 둘을 함께 덮는 묶음(consensus 항)을 하나 더 추가한다. 이 항이 전이 중에도 출력을 1로 붙잡는다.

예

F = A′D + AC′ 에서 C = 0, D = 1, B = 1 로 두고 A 가 1 → 0 으로 바뀌면 출력은 AC′ 에서 A′D 로 넘어간다. 한 곱항이 꺼지는 순간 다른 곱항이 아직 안 켜졌으면 glitch 가 생긴다.

F = A′D + AC′ + C′D

C′D 는 A 가 바뀌는 동안 계속 1이다. 논리 함수는 그대로이고 해저드만 사라진다.

  • 비용: 곱항이 하나 늘어서 회로가 커진다. 최소 SoP 가 곧 hazard-free 는 아니다.
