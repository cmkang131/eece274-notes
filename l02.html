L02. 조합 논리 (1) — 부울 대수

Combinational Logic (1)

2.1부울 대수의 기본 정리

모든 정리는 OR 형과 AND 형이 쌍으로 있다. 한쪽의 + 와 · , 0 과 1 을 서로 바꾸면 다른 쪽이 된다.

이름OR 형AND 형
멱등(idempotent)X + X = XX · X = X
항등X + 0 = XX · 1 = X
지배(null)X + 1 = 1X · 0 = 0
보수(complement)X + X′ = 1X · X′ = 0
이중 부정(X′)′ = X
교환X + Y = Y + XXY = YX
결합(X+Y)+Z = X+(Y+Z)(XY)Z = X(YZ)
분배X(Y + Z) = XY + XZX + YZ = (X+Y)(X+Z)
흡수(absorption)X + XY = XX(X + Y) = X
단순화X + X′Y = X + YX(X′ + Y) = XY
  • AND형 분배법칙 X + YZ = (X+Y)(X+Z) 는 일반 대수에는 없는 성질이다.
  • 흡수와 단순화는 식을 줄일 때 가장 자주 쓰는 도구다.

2.2드모르간과 쌍대

DE MORGAN

(X + Y)′ = X′ · Y′    (X · Y)′ = X′ + Y′

  • 드모르간: 식 전체의 보수를 구하는 규칙. 변수를 모두 보수로 바꾸고, AND와 OR을 맞바꾼다. 값이 같은 식이 나온다.
  • 쌍대(dual): 식의 AND와 OR, 0과 1을 맞바꾼 식. 변수는 그대로 둔다. 원래 식과 값이 다르다.
  • 쌍대는 "정리 하나가 성립하면 그 쌍대식도 성립한다"를 얻는 규칙이다. 식을 변환하는 도구가 아니다.
변수연산자결과
드모르간보수로 바꿈맞바꿈F′ (같은 함수의 보수)
쌍대그대로맞바꿈Fd (다른 함수)

2.3합의 정리 (consensus)

CONSENSUS

XY + X′Z + YZ = XY + X′Z

  • YZ 는 XY 와 X′Z 의 consensus 항이다. 앞의 두 항이 있으면 YZ 는 값을 바꾸지 못한다.
  • 식을 줄일 때는 consensus 항을 지운다.

예 — 단순화

F = AB + A′C + BC

BC 는 AB 와 A′C 의 consensus 항이므로 지운다.

F = AB + A′C

  • L07에서는 반대로 consensus 항을 일부러 추가해서 해저드를 없앤다.

2.4논리 게이트

게이트식출력이 1인 경우
ANDXY입력이 모두 1
ORX + Y입력 중 하나라도 1
NOTX′입력이 0
NAND(XY)′AND의 반대
NOR(X+Y)′OR의 반대
XORX ⊕ Y = X′Y + XY′입력이 서로 다름
XNOR(X ⊕ Y)′ = XY + X′Y′입력이 서로 같음
  • 범용(universal) 게이트: NAND 하나, 또는 NOR 하나만으로 모든 논리 함수를 만들 수 있다.
  • NAND로 NOT: (X·X)′ = X′
  • NAND로 AND: ((XY)′)′ = XY
  • NAND로 OR: (X′ · Y′)′ = X + Y
