2.1조합 논리와 부울 대수

조합 논리는 출력이 현재 입력에만 의존하고, 부울 대수가 그 식을 다루는 규칙이다.

조합 논리(combinational logic) = 출력이 현재 입력에만 의존하는 디지털 시스템. (cf. 순차 논리) 기술 방법은 진리표, 부울 대수, 논리 게이트다.

  • 예: tally 회로(1의 개수를 센다), 7-segment 디스플레이, 이진 가산기.

부울 대수 = 참/거짓 값 0과 1만 쓰는 대수. 대수(algebra)는 문자와 기호로 연산 규칙과 관계를 다루는 학문이다.

연산표기
NOT(보수)X′, X̄, ~X
ANDX·Y, X∧Y, X&Y, 또는 그냥 XY
ORX+Y, X∨Y, X|Y

연산 우선순위와 주의점

  • 우선순위: NOT → AND → OR. 괄호는 큰 구조를 변수 하나처럼 묶는다.
  • 예: A·B′ ≠ (AB)′. AB′ + CD = A(B′) + (CD) 이지, (B′ + CD)′ 가 아니다.
  • 0과 1은 논리 상태이지 이진수가 아니다. + 는 부울 OR 이지 이진 덧셈이 아니다. 그래서 1 + 1 = 1 이고 1 + 1 ≠ 10 이다. (1+0 = 1, 0+0 = 0)

진리표에서 식 만들기

  • 진리표에서 출력이 1인 행마다 곱항 하나가 나온다. 이 곱항들을 모두 OR 하면 sum of products(SoP) 이다.

2.2부울 대수의 법칙

공리(axioms)

  • 집합 B 에 서로 다른 두 원소 a ≠ b 가 있다.
닫힘(closure)
a, b ∈ B 이면 a+b ∈ B, a·b ∈ B.
교환
a+b = b+a, a·b = b·a.
결합
(a+b)+c = a+(b+c), (a·b)·c = a·(b·c).
항등원
0, 1 ∈ B 가 있어 a+0 = a, a·1 = a.
분배
a+(b·c) = (a+b)·(a+c), a·(b+c) = (a·b)+(a·c).
보수
a+a′ = 1, a·a′ = 0.

기본 정리

표에서 D 가 붙은 식은 왼쪽 식의 쌍대(dual)다.

법칙식쌍대(D)
0, 1 과의 연산(1) X + 0 = X(1D) X·1 = X
(2) X + 1 = 1(2D) X·0 = 0
멱등(idempotent)(3) X + X = X(3D) X·X = X
involution(4) (X′)′ = X
보수(5) X + X′ = 1(5D) X·X′ = 0
교환(6) X+Y = Y+X(6D) XY = YX
결합(7) (X+Y)+Z = X+(Y+Z) = X+Y+Z(7D) (XY)Z = X(YZ) = XYZ
분배(8) X(Y+Z) = XY + XZ(8D) X + YZ = (X+Y)(X+Z)
De Morgan(9) (X+Y)′ = X′Y′(9D) (XY)′ = X′ + Y′
  • 분배법칙의 쌍대 X + YZ = (X+Y)(X+Z) 는 일반 대수에는 없는 성질이다. 증명: (X+Y)(X+Z) = XX + XZ + YX + YZ = X + XZ + XY + YZ = X·1 + XZ + XY + YZ = X(1 + Z + Y) + YZ = X + YZ.

논리적 동등 ≠ 전기적 동등

부울식이 같아도 회로의 지연은 같지 않을 수 있다.

교환법칙
X, Y 를 바꿔 넣어도 식은 같지만, 핀 a → y 와 핀 b → y 의 지연은 같다는 보장이 없다.
결합법칙
F = (X+Y)+Z, F = X+(Y+Z), F = X+Y+Z 는 서로 다른 회로도다. X → F 경로의 지연이 서로 다르고, 이 차이를 회로 최적화에 쓸 수 있다.

De Morgan 의 법칙

DE MORGAN

(X + Y + Z + …)′ = X′ · Y′ · Z′ · …    (X · Y · Z · …)′ = X′ + Y′ + Z′ + …

  • 일반형: F(X1, …, Xn, 0, 1, +, ·)′ = F(X1′, …, Xn′, 1, 0, ·, +). 즉 변수는 보수로, 0↔1, +↔· 로 바꾼다.
  • AND 식을 OR 식으로, OR 식을 AND 식으로 바꾸는 데 쓴다. 게이트로는 AND 의 출력 반전 = 입력 반전된 OR, NOR = 입력 반전된 AND 에 해당한다.

Full adder carry-out 을 대수로 줄이기

Cout = A′BCin + AB′Cin + ABCin′ + ABCin

① ABCin 을 한 번 더 써 넣는다 (멱등·교환). A′BCin + ABCin = (A′+A)BCin = BCin (분배, 보수, 항등).

② 같은 방식으로 두 번째, 세 번째 항을 반복한다: AB′Cin + ABCin = ACin, ABCin′ + ABCin = AB.

Cout = BCin + ACin + AB

2.3단순화 정리

식에 아래 법칙을 반복 적용해 최소형을 얻는 방법이 대수적 단순화(algebraic simplification)다.

이름식쌍대(D)
(1) unitingXY + XY′ = X(X+Y)(X+Y′) = X
(2) absorptionX + XY = XX(X+Y) = X
(3) eliminationX + X′Y = X + YX(X′+Y) = XY
(4) duality(X+Y+Z+…)D = XYZ…(XYZ…)D = X+Y+Z+…
(5) multiplying out / factoring(X+Y)(X′+Z) = XZ + X′YXY + X′Z = (X+Z)(X′+Y)
(6) consensusXY + YZ + X′Z = XY + X′Z(X+Y)(Y+Z)(X′+Z) = (X+Y)(X′+Z)
  • (5) 의 증명: (X+Y)(X′+Z) = XX′ + X′Y + XZ + YZ = X′Y + XZ + YZ = X′Y + XZ (마지막은 consensus).

Consensus 정리

CONSENSUS

XY + X′Z + YZ = XY + X′Z    (X+Y)(X′+Z)(Y+Z) = (X+Y)(X′+Z)

  • YZ 는 중복(redundant)된 consensus 항이다.
  • 선택한 변수 X(X′)는 변수 하나일 필요가 없다. 예: AY + BY + A′B′Z 에서 consensus 항 찾기. AY + BY + A′B′Z = (A+B)Y + A′B′Z = (A+B)Y + (A+B)′Z = (A+B)Y + (A+B)′Z + YZ.
  • 쓰임: 논리 최소화 중에 사용한다. 식을 확장(expansion)하고 줄이는(reduction) 과정을 반복해 최소식을 얻는다. consensus 정리로 다음 단순화를 위해 식을 일시적으로 확장할 수 있다.

예 — 확장 후 축소

증명할 식: A′BD′ + BCD + ABC′ + AB′D = BC′D′ + AD + A′BC

(확장) 서로 consensus 인 항을 추가한다. A′BD′ 와 ABC′ 의 consensus 는 BC′D′, A′BD′ 와 BCD 의 consensus 는 A′BC, BCD 와 ABC′ 의 consensus 는 ABD. 좌변 = A′BD′ + BCD + ABC′ + AB′D + BC′D′ + A′BC + ABD

(축소) AB′D + ABD = AD 로 묶는다. 좌변 = A′BD′ + BCD + ABC′ + (AD + BC′D′ + A′BC)

(다시 확장) 괄호 안의 항으로 consensus 를 만든 뒤 지운다. BC′D′ 와 AD 의 consensus 는 ABC′ 이고, AD 와 A′BC 의 consensus 는 BCD 이며, BC′D′ 와 A′BC 의 consensus 는 A′BD′ 이다. 이 세 항이 모두 괄호 안 항들의 consensus 이므로 지운다.

= AD + BC′D′ + A′BC

쌍대(duality)

쌍대 식 = 식의 0↔1, AND↔OR 를 맞바꾼 식. 변수는 그대로 둔다. FD(X1, …, Xn, 0, 1, +, ·) = F(X1, …, Xn, 1, 0, ·, +)

  • 쌍대는 부울식을 변환하는 데 쓰는 것이 아니다. 결과는 원래 식과 완전히 다르다. 예: X + 0 = X 의 쌍대는 X·1 = X.
  • 쌍대 원리: 모든 부울식에는 쌍대가 있고, 참인 부울 등식의 쌍대 등식도 참이다. AND, OR, NOT 으로 쓴 식은 AND 와 OR 를 맞바꾼 쌍대 항등식을 가진다.
  • 예: (원식) 1 AND 0 = 1 → (쌍대) 0 OR 1 = 0.

XOR 와 XNOR

  • XOR: X ⊕ Y = 1 이면 (X=0 이고 Y=1) 또는 (X=1 이고 Y=0). Z = X ⊕ Y = X′Y + XY′.
  • XNOR(equivalence gate): Z = (X ⊕ Y)′ = X′Y′ + XY. 증명: (XY′ + X′Y)′ = (XY′)′(X′Y)′ = (X′+Y)(X+Y′) = X′Y′ + XY (multiplying out).
XOR (⊕)XNOR (≡)
(1)X ⊕ 0 = XX ≡ 0 = X′
(2)X ⊕ 1 = X′X ≡ 1 = X
(3)X ⊕ X = 0X ≡ X = 1
(4)X ⊕ X′ = 1X ≡ X′ = 0
(5) 교환X ⊕ Y = Y ⊕ XX ≡ Y = Y ≡ X
(6) 결합(X⊕Y)⊕Z = X⊕(Y⊕Z) = X⊕Y⊕Z(X≡Y)≡Z = X≡(Y≡Z)
(7) 분배X(Y ⊕ Z) = XY ⊕ XZX(Y ≡ Z) = XY ≡ XZ
(8)(X⊕Y)′ = X⊕Y′ = X′⊕Y = XY + X′Y′ = X≡Y(X≡Y)′ = X≡Y′ = X′≡Y = X′Y + XY′ = X⊕Y
  • (8) 에서 XOR 의 입력 하나에 붙은 bubble 은 출력 쪽으로 옮겨도 같다. 입력 bubble 은 XOR ↔ XNOR 를 바꾸고, 두 bubble 은 서로 상쇄(bubble deletion)된다.

예 — A′ ⊕ B ⊕ C 를 전개

A′ ⊕ B ⊕ C = [A′B′ + (A′)′B] ⊕ C = (A′B′ + AB) ⊕ C

= (A′B′ + AB)C′ + (A′B′ + AB)′C = (A′B′ + AB)C′ + (A′B + AB′)C

= A′B′C′ + ABC′ + A′BC + AB′C
