연산 우선순위

  • 우선순위는 NOT → AND → OR. 괄호는 큰 구조를 변수 하나처럼 묶어 줌.
  • 예: A·B′ ≠ (AB)′. AB′ + CD = A(B′) + (CD) 이지, (B′ + CD)′ 가 아니다.
  • 0과 1은 논리 상태지 이진수가 아님. + 도 부울 OR 이지 이진 덧셈이 아님. 그래서 1 + 1 = 1 이고 1 + 1 ≠ 10. (1+0 = 1, 0+0 = 0)

진리표에서 식 만들기

  • 진리표에서 출력이 1 인 행마다 곱항이 하나씩 나옴. 곱항은 입력이 1인 변수는 그대로, 0인 변수는 보수로 곱해 만듦. 이 곱항을 전부 OR 하면 sum of products(SoP).

2.2부울 대수의 법칙

axioms

  • 집합 B 에는 서로 다른 두 원소 a ≠ b 가 있음.
closure
a, b ∈ B 이면 a+b ∈ B, a·b ∈ B.
교환
a+b = b+a, a·b = b·a.
결합
(a+b)+c = a+(b+c), (a·b)·c = a·(b·c).
항등원
0, 1 ∈ B 가 있고 a+0 = a, a·1 = a.
분배
a+(b·c) = (a+b)·(a+c), a·(b+c) = (a·b)+(a·c).
보수
a+a′ = 1, a·a′ = 0.

기본 정리

표에서 (D) 가 붙은 식은 왼쪽 식의 dual.

법칙식쌍대(D)
0, 1 과의 연산(1) X + 0 = X(1D) X·1 = X
(2) X + 1 = 1(2D) X·0 = 0
idempotent(3) X + X = X(3D) X·X = X
involution(4) (X′)′ = X
보수(5) X + X′ = 1(5D) X·X′ = 0
교환(6) X+Y = Y+X(6D) XY = YX
결합(7) (X+Y)+Z = X+(Y+Z) = X+Y+Z(7D) (XY)Z = X(YZ) = XYZ
분배(8) X(Y+Z) = XY + XZ(8D) X + YZ = (X+Y)(X+Z)
De Morgan(9) (X+Y)′ = X′Y′(9D) (XY)′ = X′ + Y′
  • 분배법칙의 쌍대 X + YZ = (X+Y)(X+Z) 는 일반 대수에 없는 성질. 증명: (X+Y)(X+Z) = XX + XZ + YX + YZ = X + XZ + XY + YZ = X·1 + XZ + XY + YZ = X(1 + Z + Y) + YZ = X + YZ.

논리적 동등 ≠ 전기적 동등

부울식이 같아도 회로 지연은 다를 수 있음.

교환법칙
X, Y 를 바꿔 넣어도 식은 같음. 하지만 핀 a → y 와 핀 b → y 의 지연이 같다는 보장은 없다.
결합법칙
F = (X+Y)+Z, F = X+(Y+Z), F = X+Y+Z 는 서로 다른 회로도. 게이트를 계단식으로 연결하면 입력 위치에 따라 출력까지 거치는 게이트 수가 달라져 X → F 경로 지연이 서로 다르고, 이 차이를 최적화에 이용함.

De Morgan 의 법칙

DE MORGAN

(X + Y + Z + …)′ = X′ · Y′ · Z′ · …    (X · Y · Z · …)′ = X′ + Y′ + Z′ + …

  • 일반형: F(X1, …, Xn, 0, 1, +, ·)′ = F(X1′, …, Xn′, 1, 0, ·, +). 즉 변수는 보수로, 0↔1, +↔· 로 바꾼다.
  • AND 식 ↔ OR 식 변환에 씀. 게이트로 보면 AND 의 출력 반전 = 입력 반전된 OR, NOR = 입력 반전된 AND.

Full adder carry-out 을 대수로 줄이기

Cout = A′BCin + AB′Cin + ABCin′ + ABCin

① ABCin 을 한 번 더 써 넣는다 (멱등·교환). A′BCin + ABCin = (A′+A)BCin = BCin (분배, 보수, 항등).

② 같은 방식으로 두 번째, 세 번째 항을 반복한다: AB′Cin + ABCin = ACin, ABCin′ + ABCin = AB.

Cout = BCin + ACin + AB

2.3단순화 정리

아래 법칙을 식에 반복 적용해 최소형을 얻는 방법이 algebraic simplification.

이름식쌍대(D)
(1) unitingXY + XY′ = X(X+Y)(X+Y′) = X
(2) absorptionX + XY = XX(X+Y) = X
(3) eliminationX + X′Y = X + YX(X′+Y) = XY
(4) duality(X+Y+Z+…)D = XYZ…(XYZ…)D = X+Y+Z+…
(5) multiplying out / factoring(X+Y)(X′+Z) = XZ + X′YXY + X′Z = (X+Z)(X′+Y)
(6) consensusXY + YZ + X′Z = XY + X′Z(X+Y)(Y+Z)(X′+Z) = (X+Y)(X′+Z)
  • (5) 의 증명: (X+Y)(X′+Z) = XX′ + X′Y + XZ + YZ = X′Y + XZ + YZ = X′Y + XZ (마지막은 consensus).

Consensus 정리

CONSENSUS

XY + X′Z + YZ = XY + X′Z    (X+Y)(X′+Z)(Y+Z) = (X+Y)(X′+Z)

  • YZ 는 consensus 항이며 redundant (제거해도 식이 같음).
  • 선택한 변수 X(X′)가 꼭 변수 하나일 필요는 없다. 예: AY + BY + A′B′Z 에서 consensus 항 찾기. AY + BY + A′B′Z = (A+B)Y + A′B′Z = (A+B)Y + (A+B)′Z = (A+B)Y + (A+B)′Z + YZ.
  • 쓰임: 논리 최소화 중에 씀. consensus 항을 추가하고 항을 합치는 과정을 반복해 식을 더 간단히 만들 수 있음. 하지만 가능한 모든 식 중 항이나 리터럴 수가 가장 적은 식을 반드시 찾는 것은 아님. 추가한 항으로 다음 단순화가 가능해짐.

예 · 확장 후 축소

증명할 식: A′BD′ + BCD + ABC′ + AB′D = BC′D′ + AD + A′BC

  1. 확장: 서로 consensus 인 항을 추가.
    • A′BD′ 와 ABC′ 의 consensus 는 BC′D′
    • A′BD′ 와 BCD 의 consensus 는 A′BC
    • BCD 와 ABC′ 의 consensus 는 ABD
    좌변 = A′BD′ + BCD + ABC′ + AB′D + BC′D′ + A′BC + ABD
  2. 축소: AB′D + ABD = AD 로 묶음.좌변 = A′BD′ + BCD + ABC′ + (AD + BC′D′ + A′BC)
  3. 다시 확장 후 삭제: 괄호 안의 항으로 consensus 를 만든 뒤 지움.
    • BC′D′ 와 AD 의 consensus 는 ABC′
    • AD 와 A′BC 의 consensus 는 BCD
    • BC′D′ 와 A′BC 의 consensus 는 A′BD′
    이 세 항이 모두 괄호 안 항들의 consensus 이므로 지움.= AD + BC′D′ + A′BC

duality

  • 쌍대 식: 식의 0↔1, AND↔OR 를 맞바꾼 식.
  • 변수는 그대로.
  • FD(X1, …, Xn, 0, 1, +, ·) = F(X1, …, Xn, 1, 0, ·, +)
  • 쌍대 식은 원래 식과 같은 함수가 아님. 예: X + 0 = X 의 쌍대는 X·1 = X.
  • 쌍대 원리: 모든 부울식에 쌍대가 있으며 참인 부울 등식의 쌍대 등식도 참. AND, OR, NOT 으로 쓴 식은 AND 와 OR 를 맞바꾼 쌍대 항등식을 가짐.
  • 예: (원식) 1 AND 0 = 0 → (쌍대) 0 OR 1 = 1.

XOR 와 XNOR

  • XOR: X ⊕ Y = 1 이면 (X=0 이고 Y=1) 또는 (X=1 이고 Y=0). Z = X ⊕ Y = X′Y + XY′.
  • XNOR(equivalence gate): Z = (X ⊕ Y)′ = X′Y′ + XY. 증명: (XY′ + X′Y)′ = (XY′)′(X′Y)′ = (X′+Y)(X+Y′) = X′Y′ + XY (multiplying out).
XOR (⊕)XNOR (≡)
(1)X ⊕ 0 = XX ≡ 0 = X′
(2)X ⊕ 1 = X′X ≡ 1 = X
(3)X ⊕ X = 0X ≡ X = 1
(4)X ⊕ X′ = 1X ≡ X′ = 0
(5) 교환X ⊕ Y = Y ⊕ XX ≡ Y = Y ≡ X
(6) 결합(X⊕Y)⊕Z = X⊕(Y⊕Z) = X⊕Y⊕Z(X≡Y)≡Z = X≡(Y≡Z)
(7) 분배X(Y ⊕ Z) = XY ⊕ XZAND 는 XNOR 에 분배되지 않음. X = 0 이면 왼쪽은 0, XY ≡ XZ 는 1.
(8)(X⊕Y)′ = X⊕Y′ = X′⊕Y = XY + X′Y′ = X≡Y(X≡Y)′ = X≡Y′ = X′≡Y = X′Y + XY′ = X⊕Y
  • XOR 입력 한 곳의 bubble 은 출력 쪽으로 옮겨도 같음. bubble 하나는 XOR ↔ XNOR 를 바꾸고, bubble 두 개는 서로 상쇄 (bubble deletion).
