L11. 순차 논리 소자

Sequential Logic Elements

11.1순차 논리와 상태

순차 논리: 출력이 현재 입력과 저장된 상태(과거)의 함수다.

  • 상태(state, Q): 순차 소자의 출력값.
  • 다음 상태(next state, Q⁺): 새 입력을 받은 뒤 회로가 옮겨 가는 상태.

11.2R-S latch

SRQ⁺동작
00Qhold (유지)
010reset
101set
11Q = Q′ = 0forbidden
특성식

Q⁺ = S + R′Q   (S·R = 0 일 때)

  • S = R = 1 이면 두 출력이 모두 0 이 되어 Q′ 가 Q 의 보수라는 가정이 깨진다. 그래서 금지한다.
  • 더구나 S = R = 1 에서 S = R = 0 으로 동시에 바뀌면 최종 상태를 예측할 수 없다.

11.3gated latch와 D latch

  • Enable 이 R, S 신호를 R, S 가 의미 있을 때만 latch 에 전달한다.
  • Enable 회로가 없으면 R 이나 S 에 생긴 작은 glitch 도 출력을 바꿀 수 있다.
D LATCH

S = D, R = D′ 로 연결한다.

E = 1 이면 Q⁺ = D, E = 0 이면 Q⁺ = Q   (Q⁺ = E·D + E′·Q)

  • D latch 는 S = R = 1 이 만들어질 수 없어서 금지 입력이 없다.
  • latch 는 level 에 반응한다. E 가 1인 동안에는 D 의 변화가 그대로 출력에 나타난다.

11.4edge-triggered flip-flop

  • master-slave: 두 latch 를 반대 위상의 clock 으로 열고 닫는다. 값이 clock 의 한 순간(edge)에만 바뀐다.
  • rising edge 에서 clk 가 0에서 1로 바뀌면, master 가 닫히면서 그 순간의 D 를 붙잡고 slave 가 열려서 Q 로 내보낸다.
