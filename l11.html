L11. 순차 논리 소자

Sequential Logic Elements · 중간고사 범위

핵심 정리. 순차 논리 = 출력이 현재 입력 + 상태(과거)의 함수 · R-S latch: (조건 SR = 0, S=R=1 금지) · D latch = S=D, R=D′로 금지 상태 제거 · 플립플롭 = 에지에서만 값이 바뀜 (래치는 레벨에 반응)
개념 · R-S latch (NOR 교차 결합)
SRQ⁺동작
00Q (유지)hold
010reset
101set
11Q=Q′=0forbidden

특성식 · 제약 조건 SR = 0. S=R=1이면 보수 출력 가정이 깨진다.

그림 · R-S latch
Cross-coupled NOR R-S latch와 다음 상태 표
개념 · gated latch와 D latch
gated R-S latch: En(클럭)이 1일 때만 S, R이 반영. D latch: S = D, R = D′로 연결해 forbidden 조합을 원천 제거 — En=1이면 Q=D, En=0이면 유지.

래치는 레벨 감지: En이 켜져 있는 동안 입력 변화가 그대로 출력에 나타난다.

Gated latch — En=1 동안에만 입력 반영
개념 · edge-triggered 플립플롭
  • 래치 2개를 직렬(master-slave)로 붙이면 클럭 에지 순간의 입력만 저장.
  • edge-triggered D flip-flop: rising(또는 falling) 에지에서만 Q가 D로 갱신 — 순차 회로 설계의 기본 소자.
한 줄 요약: 래치는 레벨에 열리고 플립플롭은 에지에 동작; R-S latch의 S=R=1 금지 조건과 특성식 Q⁺ = S + R′Q는 암기.
