L03. Combinational Logic (2)

Lecture 03

3.1부울식을 회로로 만들기

  • 부울식과 회로도는 직접 대응한다. Z = A·(B·C) = A(BC) = A·B·C 이면 2-입력 AND 게이트 2개, 또는 3-입력 AND 게이트 1개가 필요하다.
  • 구현 방식은 두 가지다. (1) 시스템 보드: 개별 부품(discrete component)으로 PCB 에 구현. 필요한 부품을 고른다. (2) IC/VLSI: 라이브러리 게이트(미리 설계·검증된 셀)로 구현. 식을 쓸 수 있는 게이트에 대응시킨다.

Technology mapping = 주어진 부울 네트워크를 설계 중에 사용 가능한 라이브러리 게이트로 표현하는 과정.

라이브러리 게이트
미리 설계된 셀(AND, OR, NAND, XOR …). technology 는 공정을 뜻한다(65nm CMOS, 22nm FinFET).
왜 중요한가
하나의 부울식을 게이트에 대응시키는 방법이 여러 가지이기 때문이다. 최선의 구현을 찾는 것이 설계의 기술이다.
  • 설계 과정 = 논리 최소화 + technology mapping.

논리 블록과 계층

복잡한 함수는 기본 게이트의 모음으로 만든다. 계층 설계 예: half adder → full adder → 2-bit adder.

3.22단 논리 (Two-level logic)

  • 회로 level: 입력에서 출력까지의 경로 위에 있는 게이트 수의 최댓값. 입력단 인버터는 세지 않는다(각 입력의 true/complement 형이 모두 있다고 가정). 경로 level = 경로 위 논리 게이트 수, 회로 level = 모든 경로 level 의 최댓값.

용어

용어정의예 / 판별

  • 2단 논리는 true 입력(A, B, C …)과 complement 입력(A′, B′, C′ …)을 모두 쓸 수 있으면 어떤 함수든 구현할 수 있다.

3.3정준형 (Canonical form)

정준형 = 함수를 나타내는 표준 형태이자 함수의 유일한 대수적 서명(unique algebraic signature). 최소형은 아니다.

  • 진리표는 부울 함수의 유일한 서명이다. 진리표로 두 조합 시스템의 기능이 같은지 확인할 수 있지만, 행이 너무 많아 큰 시스템에는 쓸 수 없다(복잡도).
  • 일반 부울식은 편리하지만, 같은 진리표에 대해 식(게이트 구현)이 여러 가지 있을 수 있다.
  • 정준형은 최소형은 아니지만 유일한 서명을 준다. 진리표에서 minterm 전개 또는 maxterm 전개로 얻는다.

Minterm 과 maxterm

minterm
각 변수가 true 또는 complement 형으로 정확히 한 번(둘 다는 안 됨) 나오는 리터럴의 곱. 3변수 예: ABC ○, A′BC′ ○, (A+B)C ✕, ABA′C ✕, AB ✕.
maxterm
각 변수가 정확히 한 번 나오는 리터럴의 합. 예: A+B+C ○, A′+B+C′ ○, AB+C ✕, A+B+A′+C ✕, A+B ✕.
  • n입력 시스템에는 minterm 2n개, maxterm 2n개가 있고, 이는 진리표의 행 수와 같다.
  • minterm ⊆ 곱항, sum-of-minterms ⊆ SoP. maxterm ⊆ 합항, product-of-maxterms ⊆ PoS.
  • minterm 은 큐브 표기의 꼭짓점 하나에 대응한다.

진리표의 각 행을 minterm 에 대응시킬 때는 그 행에서만 1이 되도록 만든다. maxterm 은 그 행에서만 0이 되도록 만든다.

Minterm 전개

  • 출력이 1인 행의 minterm 을 뽑는다.
  • 뽑은 minterm 을 모두 OR 한다. 이것이 canonical sum(sum-of-minterms, SoP)이고 AND-OR 2단 회로로 구현된다.

Maxterm 전개

  • 출력이 0인 행의 maxterm 을 뽑는다.
  • 뽑은 maxterm 을 모두 AND 한다. 이것이 canonical product(product-of-maxterms, PoS)이고 OR-AND 2단 회로로 구현된다.

대수적으로 전개하기

  • 일반적인 스위칭 식은 진리표(간단함) 또는 대수적 방법(약간 까다롭지만 효율적)으로 minterm(maxterm) 전개로 바꿀 수 있다.

f(a,b,c,d) = a′(b′ + d) + acd′ 의 minterm 전개

x + x′ = 1 로 빠진 리터럴을 채우는 redundant 항을 넣는다.

f = a′b′c′d′ + a′b′c′d + a′b′cd′ + a′b′cd + a′bc′d + a′bcd + abcd′ + ab′cd′

(0000, 0001, 0010, 0011, 0101, 0111, 1110, 1010)

f = Σm(0,1,2,3,5,7,10,14), 따라서 f = ΠM(4,6,8,9,11,12,13,15)

maxterm 전개를 직접 구하기

f 를 곱의 합이 아닌 합의 곱으로 인수분해한 뒤, xx′ = 0 으로 빠진 리터럴을 채운다.

f = a′(b′+d) + acd′ = (a′ + cd′)(a′ + b′ + d) = (a′+c)(a′+d′)(a+b′+d)

= (a′+b+c+d)(a′+b′+c+d)(a′+b+c+d′)(a′+b′+c+d′) · (a′+b+c′+d′)(a′+b′+c′+d′)·(a+b′+c+d)(a+b′+c′+d)

(각 항은 1000, 1100, 1001, 1101, 1011, 1111, 0100, 0110 에 해당)

= ΠM(4,6,8,9,11,12,13,15)

등식이 성립하는지 확인하기

a′c + b′c′ + ab = a′b′ + bc + ac′ 를 양변 모두 minterm 으로 전개해 비교한다.

좌변 = a′c(b+b′) + b′c′(a+a′) + ab(c+c′) = m3 + m1 + m4 + m0 + m7 + m6

우변 = a′b′(c+c′) + bc(a+a′) + ac′(b+b′) = m1 + m0 + m7 + m3 + m6 + m4

두 쪽 모두 Σm(0,1,3,4,6,7) 이므로 같다.

두 함수의 곱

서로 다른 minterm 의 곱은 0이다. i ≠ j 이면 mimj = 0. 예: n = 3 일 때 m1m3 = (A′B′C)(A′BC) = 0.

  • f1 = Σ aimi, f2 = Σ bjmj 이면 f1f2 = Σ aibimi (mimj 는 i = j 가 아니면 0이므로). 즉 두 전개에 공통으로 들어 있는 minterm 만 남는다.
  • 예: f1 = Σm(0,2,3,5,9,11), f2 = Σm(0,3,9,11,13,14) → f1f2 = Σm(0,3,9,11).

3.4불완전하게 명시된 함수 (don’t care)

회로 설계에서는 어떤 입력 조합이 들어오지 않거나, 어떤 출력이 쓰이지 않을 수 있다. 이 경우 출력을 X(don’t care)로 표시한다. X 는 0이든 1이든 고를 수 있다는 뜻이므로 식이 간단해지는 쪽으로 정해 최적화한다.

  • 예: 입력이 BCD(binary-coded decimal)이면 10102 ~ 11112 는 절대 나타나지 않는다.
  • 구현할 때는 X 의 값을 반드시 정해야 한다. 함수가 단순해지는 값을 고른다.

3.5요약

  • Technology mapping 은 주어진 부울 네트워크를 라이브러리 게이트로 표현하는 과정이다. 논리 회로를 구현하는 방법은 여러 가지다.
  • 정준형(minterm/maxterm 전개)은 유일한 대수적 서명을 준다. minterm 전개는 출력이 1인 minterm 의 OR, maxterm 전개는 출력이 0인 maxterm 의 AND.
  • 불완전 명시 함수는 don’t care 항(X)으로 기술한다.
