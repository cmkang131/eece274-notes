L03. Combinational Logic (2)

Lecture 03

3.1부울식을 회로로 만들기

부울식 ↔ 회로도 직접 대응. 식 하나가 여러 게이트 구성으로 나옴.

  • Z = A·(B·C) = A(BC) = A·B·C 이면 2-입력 AND 2개, 아니면 3-입력 AND 1개.
  • IC/VLSI 는 라이브러리 게이트(미리 설계·검증된 셀)로 구현. 식을 쓸 수 있는 게이트에 대응시킴.

Technology mapping = 부울 네트워크를 쓸 수 있는 라이브러리 게이트로 바꿔 표현하는 과정.

라이브러리 게이트
미리 설계된 셀(AND, OR, NAND, XOR …).
왜 중요한가
부울식 하나를 게이트에 대응시키는 방법이 여럿. 최선의 구현 찾기가 설계의 일.
  • 설계 = 논리 최소화 + technology mapping.

논리 블록과 계층

복잡한 함수도 기본 게이트를 모아서 만듦. 계층 설계: half adder → full adder → 2-bit adder.

3.22단 논리 (Two-level logic)

  • 회로 level: 입력에서 출력까지 경로상 게이트 수의 최댓값. 입력단 인버터는 안 셈(입력의 true/complement 형이 둘 다 있다고 가정). 경로 level = 경로 위 논리 게이트 수, 회로 level = 경로 level 의 최댓값.

3.3정준형 (Canonical form)

정준형 = 함수의 표준 형태, unique algebraic signature. 최소형은 아님.

  • 진리표가 부울 함수의 유일한 서명. 두 조합 시스템이 같은 기능인지 확인 가능하지만 행이 너무 많아서 큰 시스템엔 불가(복잡도).
  • 일반 부울식은 편리하지만 같은 진리표라도 식(게이트 구현)이 여럿 나옴.
  • 정준형은 최소형이 아니어도 유일한 서명. 진리표에서 minterm 전개나 maxterm 전개로 얻음.

Minterm 과 maxterm

minterm
각 변수가 true 또는 complement 형으로 정확히 한 번(둘 다는 안 됨) 나오는 리터럴의 곱. 3변수 예: ABC ○, A′BC′ ○, (A+B)C ✕, ABA′C ✕, AB ✕.
maxterm
각 변수가 정확히 한 번 나오는 리터럴의 합. 예: A+B+C ○, A′+B+C′ ○, AB+C ✕, A+B+A′+C ✕, A+B ✕.
  • n입력이면 minterm 2n개, maxterm 2n개. 진리표 행 수와 같음.
  • minterm ⊆ 곱항, sum-of-minterms ⊆ SoP. maxterm ⊆ 합항, product-of-maxterms ⊆ PoS.
  • minterm = 큐브의 꼭짓점 하나.

행 하나당 minterm 하나: 그 행에서만 1. maxterm 은 그 행에서만 0.

Minterm 전개

  • 출력이 1인 행의 minterm 을 뽑는다.
  • 뽑은 minterm 전부 OR. canonical sum(sum-of-minterms, SoP). AND-OR 2단 회로로 구현.

대수적으로 전개하기

  • 일반 스위칭 식 → minterm(maxterm) 전개: 진리표에서 읽거나, 대수적으로 x + x′ = 1 을 써서 빠진 리터럴을 채움.

f(a,b,c,d) = a′(b′ + d) + acd′ 의 minterm 전개

x + x′ = 1 로 빠진 리터럴을 채움(redundant 항 추가).

f = a′b′c′d′ + a′b′c′d + a′b′cd′ + a′b′cd + a′bc′d + a′bcd + abcd′ + ab′cd′

(0000, 0001, 0010, 0011, 0101, 0111, 1110, 1010)

f = Σm(0,1,2,3,5,7,10,14) 이므로 f = ΠM(4,6,8,9,11,12,13,15)

maxterm 전개를 직접 구하기

f 를 합의 곱으로 인수분해하고 xx′ = 0 으로 빠진 리터럴을 채움.

f = a′(b′+d) + acd′ = (a′ + cd′)(a′ + b′ + d) = (a′+c)(a′+d′)(a+b′+d)

= (a′+b+c+d)(a′+b′+c+d)(a′+b+c+d′)(a′+b′+c+d′) · (a′+b+c′+d′)(a′+b′+c′+d′)·(a+b′+c+d)(a+b′+c′+d)

(각 항은 1000, 1100, 1001, 1101, 1011, 1111, 0100, 0110 에 해당)

= ΠM(4,6,8,9,11,12,13,15)

등식이 성립하는지 확인하기

a′c + b′c′ + ab = a′b′ + bc + ac′ 증명: 양변을 minterm 으로 전개해 비교.

좌변 = a′c(b+b′) + b′c′(a+a′) + ab(c+c′) = m3 + m1 + m4 + m0 + m7 + m6

우변 = a′b′(c+c′) + bc(a+a′) + ac′(b+b′) = m1 + m0 + m7 + m3 + m6 + m4

양쪽 다 Σm(0,1,3,4,6,7). 같음.

두 함수의 곱

서로 다른 minterm 의 곱은 0. i ≠ j 이면 mimj = 0. n = 3 이면 m1m3 = (A′B′C)(A′BC) = 0.

  • f1 = Σ aimi, f2 = Σ bjmj 이면 f1f2 = Σ aibimi (i ≠ j 이면 mimj = 0). 두 전개에 공통인 minterm 만 남음.
  • 예: f1 = Σm(0,2,3,5,9,11), f2 = Σm(0,3,9,11,13,14) → f1f2 = Σm(0,3,9,11).

3.4불완전하게 명시된 함수 (don’t care)

  • 입력 조합이 안 들어오거나 출력이 안 쓰이는 경우가 있음.
  • 이때 출력을 X(don’t care)로 표시.
  • X 는 0 으로 보든 1 로 보든 상관없음. 구현할 때 식이 간단해지는 값으로 정함.
  • 예: BCD(binary-coded decimal) 입력이면 10102 ~ 11112 는 안 나옴.
