L06. 다단 논리 (Multilevel Logic)

Multilevel Logic

6.1다단 논리

  • 2단 논리: 구조가 단순하고 빠르다. 항이 많아지면 AND 게이트의 입력 수(fan-in)와 게이트 수가 크게 늘어난다.
  • 다단 논리(multilevel): 공통 인수나 공통 부분식을 뽑아서(factoring) 회로를 작게 만든다.
  • 게이트 수와 입력 수는 줄지만, 신호가 지나는 단 수가 늘어 지연이 커질 수 있다.

예 — factoring

F = AC + AD + BC + BD + E

식게이트게이트 입력 수단 수
2단 SoPAC + AD + BC + BD + EAND2 4개 + OR5 1개8 + 5 = 132
factoring(A + B)(C + D) + EOR2 2개 + AND2 1개 + OR2 1개2 + 2 + 2 + 2 = 83

입력 수는 13에서 8로 줄고, 단 수는 2에서 3으로 늘었다.

6.2NAND와 NOR로 바꾸기

드모르간으로 AND-OR 회로의 게이트를 다른 종류로 바꿔도 같은 함수를 얻는다. 그림 (A) → (C) 는 SoP 를 NAND-NAND 로 바꾸는 것이다.

  • AB = (A′ + B′)′ 이므로 AND 하나는 입력을 보수로 한 NOR 와 같다. (B)
  • (AB)′ = A′ + B′ 이므로 NAND 하나는 입력을 보수로 한 OR 와 같다. (D)
  • (C): 첫 단 NAND 의 출력이 (AB)′, (CD)′ 이고, 둘째 단 NAND 가 ((AB)′ · (CD)′)′ = AB + CD 를 만든다.
회로첫 단둘째 단입력
(A) AND-ORANDORA, B, C, D
(B) NOR-ORNORORA′, B′, C′, D′
(C) NAND-NANDNANDNANDA, B, C, D
(D) OR-NANDORNANDA′, B′, C′, D′
  • 실제 회로에서는 NAND 와 NOR 가 AND, OR 보다 작고 빠르다. 그래서 SoP 를 NAND-NAND 로 만드는 것이 가장 흔하다.
