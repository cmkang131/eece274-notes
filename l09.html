9.3adder/subtractor와 overflow

OVERFLOW

overflow = Cn ⊕ Cn−1  (MSB 에서 나오는 carry 와 MSB 로 들어가는 carry)

  • 부호 있는 수(2의 보수)의 덧셈에서 결과가 표현 범위를 벗어나는 경우다.
  • 같은 부호끼리 더했는데 결과 부호가 뒤집히면 overflow 다.
  • 부호가 다른 두 수를 더할 때는 overflow 가 생기지 않는다.

예 — 4비트에서 7 + 1

0111 + 0001 = 1000. 이 값은 −8 이므로 틀렸다.

MSB 로 들어가는 carry 는 1, MSB 에서 나오는 carry 는 0 이다. 둘이 다르므로 overflow.

9.4Carry look-ahead adder (CLA)

  • ripple 방식의 지연은 carry 를 기다리는 시간이다. CLA 는 carry 를 입력만으로 미리 계산한다.

Carry Generate: Gi = Ai Bi    Carry Propagate: Pi = Ai ⊕ Bi

Ci+1 = Gi + Pi Ci    Si = Pi ⊕ Ci

  • G: 이 비트가 carry-in 에 상관없이 carry 를 만든다. (A, B 가 둘 다 1)
  • P: 이 비트가 들어온 carry 를 그대로 다음 비트로 넘긴다. (A, B 가 서로 다름)
전개

C1 = G0 + P0C0

C2 = G1 + P1G0 + P1P0C0

C3 = G2 + P2G1 + P2P1G0 + P2P1P0C0

  • 모든 Ci 가 G, P, C0 만으로 표현되므로 동시에 계산된다.
  • 비트 수가 커지면 식이 길어지고 AND 게이트의 fan-in 이 폭증한다.
  • hierarchical CLA: 4비트 블록마다 P, G 를 만들고, 그 P, G 를 다시 look-ahead 로 묶어서 해결한다.
블록 P, G

P3:0 = P3P2P1P0

G3:0 = G3 + P3G2 + P3P2G1 + P3P2P1G0
