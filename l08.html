L08. Combinational Logic Technologies

Lecture 08

8.1기본 논리 구성요소 (교재 4.2)

Fixed gates

  • 기능이 고정되어 있다(프로그램할 수 없음). 고정 게이트의 논리 기능은 카탈로그에 나와 있다.
  • 다양한 패키지 형태가 있다(예: dual in-line package). 예: TTL 7400 NAND(1966). 브레드보드, PCB(printed circuit board)에 꽂아 쓴다.

Look-up table (LUT)

  • 현재 입력값으로 표를 인덱싱해서 함수의 출력이 무엇이어야 하는지 찾아본다.
  • 종류: ROM(read only memory), MUX(multiplexer).
  • 구현: 주어진 논리 함수의 입력 조합별 출력을 나타내는 표(LUT)를 만든다. 그런 다음 LUT 의 내용을 (거의) 그대로 하드웨어의 논리 소자로 구현에 쓴다.

ROM (Read Only Memory)

  • 읽기 동작(read operation)만 한다. 데이터는 제조할 때 쓴다(cf. PROM, EPROM, Flash). 비휘발성(non-volatile)이라 전원을 꺼도 데이터가 사라지지 않는다.
  • 구조: 디코더 + 메모리 배열.
  • n입력 주소 디코더가 2n개의 word line 중 하나를 활성화한다. ROM 의 출력을 나타내는 각 세로 선이 bit line 이다.

Multiplexer (MUX)

MUX 는 입력 중 하나를 골라 출력으로 전달한다. 어느 입력을 고를지는 선택 신호(selection signal, control input)로 정한다. 2n:1 MUX 는 선택 신호 n개로 2n개의 입력 중 하나를 출력 Z 에 전기적 또는 논리적으로 연결한다.

  • 질문: 선택 신호가 3비트(A, B, C)이면 몇 개의 입력 중에서 정확히 하나를 고를 수 있나? → 23 = 8개.

MUX 식

2:1   Z = A′I0 + AI1

4:1   Z = A′B′I0 + A′BI1 + AB′I2 + ABI3

구현 예: 2:1 MUX 는 AND-OR 로, 4:1 MUX 는 AND-OR 또는 NAND-NAND 로 만든다.

8.2MUX 로 조합 논리 설계하기

하드웨어 look-up table: n비트 선택 입력을 가진 MUX 는 n변수 진리표를 하드웨어에 직접 구현한다. 선택 신호가 n개보다 적은 MUX 로도 n변수 진리표를 구현할 수 있다. 이때는 모자라는 선택 신호를 보충하는 입력 회로가 필요하다.

예 — F(A,B,C) = m0 + m2 + m6 + m7 = A′B′C′ + A′BC′ + ABC′ + ABC

8:1 MUX 의 선택 신호 S2 S1 S0 에 A B C(LSB)를 연결하고 데이터 입력 I0~I7 에 진리표의 F 를 그대로 연결한다.

ABCF입력
0001I0 = 1
0010I1 = 0
0101I2 = 1
0110I3 = 0
1000I4 = 0
1010I5 = 0
1101I6 = 1
1111I7 = 1

같은 논리를 4:1 MUX(S0, S1)로 설계하는 방법 세 가지: ① 부울식 ② 진리표 ③ K-map.

방법 1: 부울식

F = m0 + m2 + m6 + m7 = A′B′C′ + A′BC′ + ABC′ + ABC = A′B′C′ + A′BC′ + AB

= A′B′(C′) + A′B(C′) + AB′(0) + AB(1) → A′B′(I0) + A′B(I1) + AB′(I2) + AB(I3)

따라서 I0 = C′, I1 = C′, I2 = 0, I3 = 1.

방법 2: 진리표

A B 가 같은 두 행씩 묶어, 남은 변수 C 에 대한 F 의 모양을 읽는다. AB = 00: C = 0 이면 1, C = 1 이면 0 → C′. AB = 01 도 C′. AB = 10 은 항상 0. AB = 11 은 항상 1.

방법 3: K-map

K-map 열의 순서가 gray code 이므로 MUX 입력 순서 I0 I1 I3 I2 로 읽는다.

8.3Template-based logic

  • 커스터마이즈해서 많은 함수 중 하나를 구현할 수 있는 설계 템플릿에 기반한다. 예: decoder/demultiplexer, PLA(programmable logic array).

Decoder / DeMUX

  • DeMUX 는 입력 하나를 여러 출력 중 하나에 연결한다. n비트 제어 입력이 2n개의 출력 중 하나를 선택한다.
  • Decoder 는 코드화된 입력을 코드화된 출력으로 바꾼다. minterm generator 로 쓸 수 있다: N비트 입력, 2N비트 출력 → N:2N decoder. 1:2 decoder 는 1비트 minterm 생성기, 2:4 decoder 는 2비트 minterm 생성기.
  • 논리 구성요소로서의 decoder: n변수의 모든 SoP 식은 n:2n decoder 와 OR 게이트로 구현할 수 있다.

예 — 4:16 decoder (Enable 있음) 로 3개 함수 구현

F1 = A′BC′D + A′B′CD + ABCD = Σm(3, 5, 15)

F2 = ABC′D′ + ABCD′ + ABCD = Σm(12, 14, 15)

F3 = (A′ + B′ + C′ + D′) = (ABCD)′ — decoder 출력 15 를 인버터로 반전

각 함수는 해당 minterm 의 decoder 출력들을 OR 게이트로 합쳐서 만든다. F3 은 minterm 이 하나(m15)뿐인 함수의 보수이므로 OR 대신 반전만 한다.

PLA (Programmable Logic Array)

  • AND/OR 게이트가 많이 들어 있는, 미리 설계된 빌딩 블록. 제조할 때 또는 현장에서(in the field) 게이트 연결을 만들거나 끊어서 개별화한다.
  • AND plane: 입력과 그 보수를 가로지르는 선 위에서 필요한 곱항을 프로그래밍한다. OR plane: 어느 곱항을 어느 출력에 더할지 프로그래밍한다.
  • 곱항을 출력끼리 공유하므로 출력마다 minterm 을 전부 만드는 ROM 보다 작게 만들 수 있다.

PLA 구현 예

F0 = A + B′C, F1 = AC′ + AB, F2 = B′C + AB, F3 = B′C′ + A

8.4Tri-state 출력 (교재 4.4)

  • Buffer(OUT = IN): 게이트 출력의 구동 능력을 키우는 데 쓴다(bubble 없음).
  • Tri-state: 구동 능력과 관련된 세 번째 상태 “Z”. tri-state 논리 게이트는 논리 0 과 1 에 더해 세 번째 상태 Z 가 있다.
  • 논리 0 과 1 은 논리 상태(state)라고 부르지만 더 정확하게는 논리 레벨(level)이다.
  • 세 번째 상태 Z 는 게이트의 출력 임피던스가 매우 높다는 뜻이다(이상적으로는 무한대) = 연결이 없다(no connection).
