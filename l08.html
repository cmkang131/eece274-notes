방식구성특징

8.2mux 로 조합 논리 만들기

4:1 mux 의 출력: F = A′B′·I0 + A′B·I1 + AB′·I2 + AB·I3

  • 선택 입력 두 개에 변수 두 개를 연결한다.
  • 선택 입력의 조합마다, 남은 변수 C 에 대한 F 의 값을 읽어서 데이터 입력에 연결한다. 값은 0, 1, C, C′ 중 하나가 된다.

예 — 3변수 함수를 4:1 mux 로

ABCF데이터 입력
0001
0010I0 = C′
0101
0110I1 = C′
1000
1010I2 = 0
1101
1111I3 = 1

AB = 00 이면 C 가 0일 때 F = 1, C 가 1일 때 F = 0 이므로 I0 = C′ 이다. AB = 01 도 같다.

AB = 10 이면 F 는 항상 0, AB = 11 이면 항상 1 이다.

식으로 쓰면 F = A′B′C′ + A′BC′ + AB = A′C′ + AB

8.3PLA

  • AND plane: 입력과 그 보수를 가로지르는 선 위에서 필요한 곱항을 프로그래밍한다.
  • OR plane: 어떤 곱항을 어느 출력에 더할지 프로그래밍한다.
  • 곱항을 출력끼리 공유하기 때문에, 출력마다 minterm 을 전부 만드는 ROM 보다 작게 만들 수 있다.
