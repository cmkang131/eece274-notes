8.1기본 논리 구성요소 (교재 4.2)

재료는 세 가지: fixed gates, look-up table, template-based logic.

Fixed gates

기능이 고정돼 있어 프로그램 불가능한 게이트.

기능
논리 기능은 카탈로그에 적혀 있음.
패키지
형태는 여러 가지(예: dual in-line package). 브레드보드나 PCB(printed circuit board)에 꽂아 씀.
예
TTL 7400 NAND (1966)

Look-up table (LUT)

입력값으로 표를 인덱싱해 함수 출력을 찾아봄.

종류
ROM (read only memory), MUX (multiplexer)
구현 순서
먼저 입력 조합별 출력을 적은 표(LUT)를 만들고, 그 내용을 (거의) 그대로 하드웨어 논리 소자에 옮겨 구현.

ROM (Read Only Memory)

읽기 전용 메모리. 구조는 디코더 + 메모리 배열.

동작
read operation만 가능. 데이터는 제조할 때 기록 (cf. PROM, EPROM, Flash).
비휘발성
non-volatile 이라 전원을 꺼도 데이터가 남음.
word line
n입력 주소 디코더가 2n개 word line 중 하나를 활성화.
bit line
ROM 출력에 해당하는 세로 선 하나하나.

Multiplexer (MUX)

  • MUX 는 입력 하나를 골라 출력으로 넘김.
  • 고르는 건 selection signal(control input).
  • 2n:1 MUX 는 선택 신호 n개로 입력 2n개 중 하나를 출력 Z 에 전기적 또는 논리적으로 이어 줌.
  • 선택 신호가 3비트(A, B, C)면 입력 몇 개 중에서 하나를 고르나? 23 = 8개.

Z = A′I0 + AI1. A = 0 이면 Z = I0, A = 1 이면 Z = I1 (functional form, logical form).

MUX 식

2:1   Z = A′I0 + AI1

4:1   Z = A′B′I0 + A′BI1 + AB′I2 + ABI3

8:1   Z = A′B′C′I0 + A′B′CI1 + A′BC′I2 + A′BCI3 + AB′C′I4 + AB′CI5 + ABC′I6 + ABCI7

구현 예. 2:1 MUX 는 AND-OR, 4:1 MUX 는 AND-OR 또는 NAND-NAND.

8.2MUX 로 조합 논리 설계하기

  • 하드웨어 look-up table: n비트 선택 입력의 MUX 는 n변수 진리표를 하드웨어로 바로 구현함.
  • 선택 신호가 n개보다 적은 MUX 로도 n변수 진리표 구현 가능.
  • 대신 모자란 선택 신호를 채워 줄 입력 회로가 필요.

예 · F(A,B,C) = m0 + m2 + m6 + m7 = A′B′C′ + A′BC′ + ABC′ + ABC

8:1 MUX 의 선택 신호 S2 S1 S0 에 A B C(LSB)를 연결하고, 데이터 입력 I0~I7 에는 진리표의 F 를 그대로 연결.

ABCF입력
0001I0 = 1
0010I1 = 0
0101I2 = 1
0110I3 = 0
1000I4 = 0
1010I5 = 0
1101I6 = 1
1111I7 = 1

같은 논리를 4:1 MUX(S0, S1)로 설계.

부울식으로 구하기

F = m0 + m2 + m6 + m7 = A′B′C′ + A′BC′ + ABC′ + ABC = A′B′C′ + A′BC′ + AB

= A′B′(C′) + A′B(C′) + AB′(0) + AB(1) → A′B′(I0) + A′B(I1) + AB′(I2) + AB(I3)

∴ I0 = C′, I1 = C′, I2 = 0, I3 = 1.

8.3Template-based logic

  • 여러 함수 중 원하는 걸 골라 구현하도록 맞춰 쓰는 설계 틀. 예: decoder/demultiplexer, PLA(programmable logic array).

Decoder / DeMUX

DeMUX
입력 하나를 여러 출력 중 하나로 보냄. n비트 제어 입력이 2n개 출력 중 하나를 선택.
Decoder
코드화된 입력을 코드화된 출력으로 바꿈. minterm generator 로 쓰임. N비트 입력, 2N비트 출력이면 N:2N decoder.
크기
1:2 decoder = 1비트 minterm 생성기, 2:4 decoder = 2비트 minterm 생성기.
논리 구성요소
n변수 SoP 식은 어느 것이든 n:2n decoder + OR 게이트로 구현 가능.

예 · 4:16 decoder (Enable 있음) 로 3개 함수 구현

F1 = A′BC′D + A′B′CD + ABCD = Σm(3, 5, 15)

F2 = ABC′D′ + ABCD′ + ABCD = Σm(12, 14, 15)

F3 = (A′ + B′ + C′ + D′) = (ABCD)′, decoder 출력 15 를 인버터로 반전

각 함수는 해당 minterm 의 decoder 출력을 OR 게이트로 합쳐서 구현. F3 은 minterm 하나(m15)짜리 함수의 보수라서 OR 없이 반전만 하면 됨.

PLA (Programmable Logic Array)

AND/OR 게이트가 잔뜩 들어 있는 미리 설계된 빌딩 블록.

개별화
제조 시 또는 현장에서(in the field) 게이트 연결을 만들거나 끊어서 개별화.
AND plane
입력과 그 보수가 지나는 선 위에서 필요한 곱항을 프로그래밍.
OR plane
어느 곱항을 어느 출력에 더할지 프로그래밍.
특징
곱항을 출력끼리 공유해서 출력마다 minterm 을 전부 만드는 ROM 보다 작게 만듦.

PLA 구현 예

F0 = A + B′C, F1 = AC′ + AB, F2 = B′C + AB, F3 = B′C′ + A

8.4Tri-state 출력 (교재 4.4)

  • Buffer(OUT = IN): 게이트 출력의 구동 능력을 키울 때 씀(bubble 없음).
  • Tri-state: 구동 능력과 관련된 세 번째 상태 “Z”. 논리 0, 1 에 더해 Z 상태를 가진 게이트.
  • 논리 0, 1 은 흔히 state라 부르지만 정확히는 논리 레벨.
  • Z 는 출력 임피던스가 매우 높은 상태(이상적으로 무한대). 곧 연결이 없는 것(no connection).
